## 将棋
基本的な将棋をUnityで作りました

## 画像
![画像](https://github.com/Ryoncy-Git/syougi/blob/master/Assets/!Introduce/%E3%82%B9%E3%82%AF%E3%83%AA%E3%83%BC%E3%83%B3%E3%82%B7%E3%83%A7%E3%83%83%E3%83%88%202025-07-31%20135710.png)

## 操作説明
マウス操作のみで行います。駒をクリックし、行先をクリックすると駒が動きます。手駒を打つ場合は右下の手駒をクリックしてから打つ場所をクリックすると出せます。
その他各種操作もすべてUI上で行います。

## 実装環境
Unity6000.0.44f1

## 特徴
基本的な将棋です。
操作はすべてマウスから入力可能になっています。

## 実装時のこだわり
後からいろいろな機能を追加するときにもやりやすいよう、拡張性、保守性に富んだコードを書くよう意識しました。単一責任原則を意識し、コードの流れを追いやすくしています。コードは結構きれいにかけたと思っています。
なるべく自作アセットを用い、外部アセットは使わないようにしています。駒のイラスト、C#スクリプト、UIなど、すべて自力で用意しました。

#苦労したコト
各駒の種類をクラスで管理するかどうかを悩みました。結果としてenumを使って場合分けをしていますが、クラス継承を使った方がよかったかもしれないと後悔しながら作っています。今後新たに追加要素を加えたいため、拡張しやすいようかなり細かく実行の流れ組みました。

## 今後の展望
- 駒に別ベクトルの強さの概念を導入し、通常とは少し違う将棋ができるように考えています。
- Photon Unity Networkを用いて特定の人とネットワーク対戦をできるように考えています。
