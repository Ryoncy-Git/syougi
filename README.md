## 将棋
Unity（C#）を用いて、盤面管理・駒ロジック・UI操作をすべて自作した将棋ゲームです。  
機能追加やルール拡張を想定し、保守性を意識した構成で実装しています。

## 操作説明
マウス操作のみで行います。  
駒をクリックし、行先をクリックすると駒が動きます。  
手駒は右下UIから選択して配置。  
すべてマウス操作、UIで完結しています。  

## 実装環境
Unity6000.0.44f1

## 実装時のこだわり
後からいろいろな機能を追加するときにもやりやすいよう、拡張性、保守性に富んだコードを書くよう意識しました。単一責任原則を意識し、駒に関するロジック、盤面管理、UI管理などは分離しています。  
なるべく自作アセットを用い、外部アセットは使わないようにしています。駒のイラスト、C#スクリプト、UIなど、すべて自力で用意しました。

## 苦労したコト
各駒の種類をクラスで管理するかどうかを悩みました。enumを使うことによりswitch文で簡単に処理を分岐できるため良と思いenumを使いました。しかし、親クラスとして駒すべてに共通するメソッドを仮想関数として、子クラスでオーバーライドしたほうがわかりやすい実装になったのではと後悔しています。  
今後新たに追加要素を加えたいため、拡張しやすいようかなり細かく実行の流れ組みました。

## 今後の展望
- 駒に別ベクトルの強さの概念を導入し、通常とは少し違う将棋ができるように考えています。具体的には、敵を倒すたびにその駒が強くなり、同じ種類の駒でも差を持たせてみようと考えています。  
- Photon Unity Networkを用いて特定の人とネットワーク対戦をできるように考えています。その場合、画面下が自陣になるようUIを調整したり、駒を動かしたタイミングで同期処理を呼びローカルで演算して負荷を減らそうと考えています。
